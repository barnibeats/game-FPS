# game-fps

Лёгкий HUD с реальным FPS для Windows 10 / 11 в выбранном углу экрана (в играх и на рабочем столе) со встроенной очисткой standby-списка памяти.

[English version](README.md)

## Почему он лёгкий

- Один нативный C++ exe (~300 КБ), без рантаймов и установщика.
- FPS берётся из ETW-сессии `Microsoft-Windows-DxgKrnl` (только события Present), как в PresentMon. Никаких хуков и инъекций, поэтому античиты не срабатывают.
- FPS рабочего стола — реальная частота композиции DWM.
- Окно перерисовывается только при смене текста, приоритет ниже обычного, EcoQoS. ~5 МБ RAM, ~0% CPU.
- Скрыли HUD — ETW-сессия полностью останавливается.

## Возможности

- Любой угол экрана, основной монитор или монитор активного окна.
- Дополнительно: время кадра, 1% low, загрузка RAM.
- Размер, цвет, прозрачность, интервал обновления.
- Живёт в трее: ЛКМ — показать/скрыть, ПКМ — меню.
- Автозапуск с Windows (задача планировщика, без запроса UAC при входе).
- **Очистка памяти** в стиле Intelligent Standby List Cleaner: вручную или автоматически, когда `standby ≥ N МБ` и `свободно < M МБ`.
- Горячие клавиши: `Ctrl+Alt+F` — HUD, `Ctrl+Alt+M` — очистка standby.

## Установка и обновления

Всё распространяется через [GitHub Releases](https://github.com/barnibeats/game-FPS/releases): скачайте `game-fps-vX.Y.Z-win-x64.zip`, распакуйте и запустите `game-fps.exe`. Для обновления скачайте новый релиз (трей → «Проверить обновления»). К релизу приложена контрольная сумма SHA-256.

Нужны права администратора (ETW и управление списками памяти).

## Настройки

Всё доступно в меню трея. Файл `%APPDATA%\game-fps\settings.ini` можно править вручную.

## Сборка

```powershell
cmake -S . -B build -G Ninja
cmake --build build
```

Нужен CMake ≥ 3.16 и MSVC или MinGW-w64.
